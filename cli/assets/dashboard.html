Run metadata

How this run was configured — the scenario, the random seed, how many ticks it covered, and which agent personas took part. Use this to tell at a glance what kind of simulation you're looking at (lending, perps, AMM, or a historical replay) and how to reproduce it.

Summary metrics

End-of-run aggregate numbers emitted by the adapter. Units and field names come from the adapter itself, so a lending run surfaces things like TVL and bad debt, a perps run surfaces open-interest and PnL, and so on. "Normal" depends on the scenario — compare across seeds to see what holds.

Agents

Who acted and how it went. Grouped by persona archetype: how many agents of this type ran, how many actions they fired, what fraction succeeded vs reverted, and (where causal data is available) which invariant fires traced back to their actions.

Invariants

Machine-checkable rules the run is watching. Red rows mean a rule fired during this run — the condition was violated at least once. A clean run shows every rule at zero firings.

Timeseries

Per-tick values recorded as the simulation advanced. Pick a series to plot against tick number. Flat means the metric held steady; sharp moves line up with events below. Adapter decides which fields are numeric and chart-worthy.

Event stream

Every action an agent attempted, in tick order. Green outcomes succeeded, red ones failed, amber ones were skipped (e.g. precondition not met). Filter by action, outcome, or agent substring to zoom in. Large runs are capped at 2000 rendered rows — the raw stream is linked below.
